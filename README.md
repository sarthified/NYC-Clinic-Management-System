# NYC Clinic Management System

A menu-driven Clinic Management System developed using Python and MySQL as a Class 12 project.

## Features

* Patient registration and login
* Doctor appointment booking
* Appointment viewing
* Bill generation and viewing
* Medicine inventory management
* Pharmacist registration and login
* Admin functions for managing doctors and appointment slots

## Technologies Used

* Python
* MySQL
* CSV file handling

## Requirements

* Python 3
* MySQL Server
* The `mysql-connector-python` package

## Setup Instructions

1. Install Python and MySQL.

2. Install the required Python package:

   `pip install -r requirements.txt`

3. Configure the MySQL connection settings in `main.py` for your local MySQL installation.

4. Run the program:

   `python main.py`

The program contains database setup code and creates the medicine CSV file when required.

## Project Note

This project was developed as a Class 12 project to practise Python programming, database connectivity, SQL queries, and file handling.
